# Тест-кейсы — Спринт 1 (Базовый каркас и стартовый экран)

## TC-01. Запуск приложения на эмуляторе / устройстве
| Поле | Описание |
| :--- | :--- |
| **ID** | TC-01 |
| **Функция** | Запуск приложения и инициализация главного экрана |
| **Предусловие** | Проект `AttendanceControl` собран без ошибок; эмулятор Android (или физическое устройство) запущен. |
| **Шаги** | 1. Нажать кнопку **Run** в Android Studio.<br>2. Дождаться установки APK и автоматического запуска приложения на устройстве. |
| **Ожидаемый результат** | Приложение успешно запускается, не завершается аварийно (нет ошибок *App keeps stopping*), открывается главный экран приложения (`MainActivity`). |
| **Статус (Спринт 1)** | **Пройден (Pass)** |

| Поле | Описание |

## TC-03. Реакция кнопок навигации на нажатие
| Поле | Описание |
| :--- | :--- |
| **ID** | TC-03 |
| **Функция** | Обработка нажатий кнопок главного меню и переход на экраны-заглушки |
| **Предусловие** | Открыт главный экран приложения. |
| **Шаги** | 1. Нажать на кнопку **«Студенты»**, затем вернуться назад системной кнопкой *Back*.<br>2. Нажать на кнопку **«Отметить посещаемость»**, затем вернуться назад.<br>3. Нажать на кнопку **«Статистика»**, затем вернуться назад. |
| **Ожидаемый результат** | Каждая кнопка реагирует на нажатие без зависаний и вылетов: открывается соответствующий экран-заглушка (`StudentsActivity`, `AttendanceActivity`, `StatisticsActivity`), системная кнопка *Back* корректно возвращает пользователя на главный экран. |
| **Статус (Спринт 1)** | **Пройден (Pass)** |
