## 1. Выполненные задачи

1. **Проверка рабочего окружения и SDK:**
    * Проверена установка и корректность работы Android Studio, Android SDK и системного образа эмулятора (AVD).
    * Выполнен пробный запуск стандартного шаблона Android-приложения на языке Kotlin на эмуляторе; подтверждено отсутствие ошибок сборки Gradle и совместимость конфигураций.
2. **Настройка системы контроля версий (Git / Мос):**
    * Инициализирован единый командный репозиторий, настроена основная ветка `main`.
    * Добавлен файл `.gitignore` для исключения локальных и временных файлов сборки (`.gradle/`, `.idea/`, `build/`, `local.properties`).
    * Проверена интеграция коммитов участников команды: выполнено тестовое клонирование репозитория и сборка проекта «с нуля», подтверждено отсутствие зависимости от локальных файлов разработчика.
3. **Разработка тестовой документации и проведение проверок:**
    * Создан файл `TEST_CASES.md`, в котором описаны 3 базовых тест-кейса (`TC-01` — `TC-03`).
    * Проведено ручное тестирование собранного APK на эмуляторе после объединения изменений команды.
4. **Документирование запуска:**
    * Составлена и добавлена в `README.md` пошаговая инструкция по клонированию, сборке и запуску проекта в Android Studio.
