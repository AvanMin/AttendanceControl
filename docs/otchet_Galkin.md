# Отчёт Lead Developer по итогам Спринта 4: «Постоянное хранение данных»

**Проект:** Система контроля посещаемости студентов (`AttendanceControl`)  
**Дата проведения:** День 4  
**Роль:** Lead Developer (Участник Б)

---

## 1. Выполненные технические задачи

* **Подключение библиотеки Room:**
  * Проверены и добавлены необходимые зависимости `androidx.room` (Runtime, Compiler / KSP) в файл `build.gradle.kts`.
  * Настроена совместимость с асинхронными вызовами (`coroutines`) для работы с базой данных в фоновых потоках.

* **Создание сущностей (`Entity`):**
  * Реализован класс `StudentEntity` с аннотациями `@Entity(tableName = "students")` и `@PrimaryKey(autoGenerate = true)`.
  * Реализована сущность `AttendanceEntity` для сохранения отметок посещаемости с привязкой по идентификатору студента, дате занятия и статусу.

* **Реализация объектов доступа к данным (`DAO`):**
  * Создан интерфейс `StudentDao` с поддержкой асинхронных методов (`suspend`): добавление (`@Insert`), получение всего списка с сортировкой (`@Query`) и удаление (`@Delete`).
  * Создан интерфейс `AttendanceDao` для сохранения и извлечения истории посещений.

* **Создание и настройка базы данных (`AppDatabase`):**
  * Спроектирован абстрактный класс `AppDatabase`, расширяющий `RoomDatabase`, с описанием списка сущностей и версией базы данных.
  * Реализован паттерн Singleton для безопасного получения единственного экземпляра базы данных на уровне приложения.

* **Интеграция с UI:**
  * Переписана логика экранов списков и добавления данных с временных коллекций на реальные запросы к `Room DAO` через `lifecycleScope` / корутины.
  * Проверена работа интерфейса при перезапуске приложения (сохранение консистентности данных).
