# Отчёт по Спринту 1 — Lead Developer (LD)

**Статус:** Выполнен

## Выполнено
* Создан Android-проект на Kotlin с XML-разметкой (`ru.college.attendance`).
* Свёрстан главный экран (`activity_main.xml`) с названием и кнопками: «Студенты», «Отметить посещаемость», «Статистика».
* Созданы заготовки экранов в пакете `ui/` (`StudentsActivity`, `AttendanceActivity`, `StatisticsActivity`) и настроена навигация через `Intent`.

## Технические решения
* Использован шаблон **Empty Views Activity** (XML + `AppCompatActivity`).
* Экраны вынесены в пакет `ui/` для разделения интерфейса и будущего слоя данных.
