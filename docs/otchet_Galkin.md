### Выполненные задачи
* **Описан сценарий проведения занятия:** определена последовательность действий преподавателя (выбор даты, учебной группы и дисциплины -> переход к списку студентов группы -> выставление статусов -> сохранение).
* **Составлены User Stories и критерии приёмки (US-07 – US-10):**
    * **US-07 (Создание занятия):** запрет перехода к списку без заполнения обязательных полей (дата и группа).
    * **US-08 (Выбор статуса):** утверждены три итоговых статуса — *«Присутствовал»*, *«Отсутствовал»*, *«Опоздал»*.
    * **US-09 (Комментарий):** добавлено опциональное поле для указания причины опоздания или отсутствия.
    * **US-10 (Сохранение и уникальность):** зафиксировано бизнес-правило — на одного студента в рамках одного занятия хранится только одна итоговая отметка; при повторной отметке статус перезаписывается.
* **Проведена приёмка функционала:** выполнена демонстрация готовых экранов, проверено соответствие реализации всем критериям приёмки.
