Цель спринта: определить требования к системе, создать основу Android-приложения, настроить репозиторий и проверить запуск стартового экрана.

Создан Android-проект AttendanceControl на Kotlin с XML-разметкой.

Проверены Android Studio, Android SDK и запуск приложения на эмуляторе.

Подготовлен файл TEST_CASES.md с тремя тест-кейсами: запуск приложения, отображение главного экрана и работа кнопок.

Проведено ручное тестирование APK после объединения изменений команды.

В README.md добавлена инструкция по клонированию, сборке и запуску проекта.

2. Результаты тестирования

По отчёту QA / DevOps, все три проверки завершились успешно:

TC-01 — приложение устанавливается и запускается, MainActivity открывается без аварийного завершения. Статус: Pass.

TC-02 — заголовок и кнопки главного экрана отображаются корректно. Статус: Pass.

TC-03 — кнопки открывают соответствующие экраны-заглушки, системная кнопка Back возвращает на главный экран. Статус: Pass.
